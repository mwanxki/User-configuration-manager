# User Configuration Manager

A beginner-friendly Python project that allows users to manage application settings using Python dictionaries and functions.

## Features

- Add new user settings.
- Update existing settings.
- Delete settings.
- View all current settings.
- Prevent duplicate settings.
- Handle attempts to update or delete non-existing settings.

## Concepts Practised

- Python dictionaries
- Functions
- Tuples
- Conditional statements
- For loops
- String methods
- Dictionary manipulation

## How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open the integrated terminal.
4. Run:

```bash
python user_config_manager.py
```
